# Kataleya · iPhone SE Safari test

**Case:** `WO-KATALYEYA-IPHONE-SE`

**Status:** ready for owner test

**Device:** iPhone SE (3rd generation)
**Scope:** current Kataleya demo only; no account or personal data needed

## Install it

1. Open **Safari** on the iPhone and go to <https://kontor.studio/kataleya-demo/>.
2. Tap **Share**.
3. Tap **Add to Home Screen**. If it is missing, scroll down to **Edit Actions** and add it.
4. Turn on **Open as Web App**, then tap **Add**.
5. Tap the new Kataleya icon on the Home Screen.

This creates an iPhone Home Screen web app. It is not an App Store download or a native iOS build. The link is the existing deployed demo, so this checks the current release on real Safari; it does not test an unreleased private build.

## Five quick checks

- **Fit:** Open the home/room screen in portrait. Check that the title, orb, and main action fit without odd cutouts or clipped controls.
- **Breathing:** Run three cycles. Check that the orchid petals visibly follow the breathing pace, stay crisp, and have no square shadow or smeared glow.
- **Check-in:** Tap check-in once. Confirm the status message appears near the action and is easy to notice.
- **Sun and moon:** Open their screen. Check that sun, moon, rise/set, and the current Circadian phase/name are clearly distinguished.
- **Reach and text:** Try the main actions one-handed, then increase text size once in iPhone settings and confirm buttons and labels remain usable.

Use ordinary demo content only. Do not enter passwords, health history, contact details, or anything private. If something fails, send the screen name, what you tapped, and what happened; a screenshot is useful if it contains no personal information.

## What this does not test

It does not validate an App Store/native iOS build. Khaos Hub's separate synthetic fixture remains local-only until the Tailnet allow/deny policy is reviewed and the private route is explicitly verified. Do not use that fixture URL or change Tailnet, VPN, or DNS settings for this Kataleya check.

Apple's current install steps: [Turn a website into an app in Safari on iPhone](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/27/ios/27).
