## Pre-event check

- [ ] Play every file from beginning to end on the playback device.
- [ ] Confirm playlist order and transitions; remove dead air and accidental duplicates.
- [ ] Set a safe output level and verify speech is understandable without clipping.
- [ ] Confirm the microphone, cable, input, and speaker path if used.
- [ ] Keep spare cables/adapters nearby and route cables away from walkways.
- [ ] Put a backup playlist on a second device and verify it opens offline.
- [ ] Confirm the venue allows the planned sound level and equipment.
